## 言語パックの編集

1. 日本語またはEnglishを選び、「選択した言語パックを書き出す」で保存します。
2. メモ帳などでUTF-8として開き、`=`の右側を編集します。
3. 「言語パックを読み込み／再読み込み」で編集したファイルを選択します。
4. 「言語設定を保存」を押し、アプリを再起動します。

```ini
# コメント
menu.example=表示する文章
```

先頭の`#`または`;`はコメント、空行は無視します。キーの重複や書式エラーは
行番号付きで表示します。改行は`\n`、文字としてのバックスラッシュは`\\`です。
最初の`=`より後は値なので、値に`=`も使えます。空の値や不足項目は英語で補います。
パックにコードを記述しても実行されません。読み込み上限は1MBです。
読み込んだ内容のコピーをローカル設定に保存するため、元ファイルを移動しても使えます。
ファイルの編集後は再度読み込んでください。

`app/static/locales/en.ini`と`ja.ini`が編集用サンプルです。
同梱辞書のJSONとサンプルの一致はテストで確認しています。
