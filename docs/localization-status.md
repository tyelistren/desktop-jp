## 再調査

依存パッケージを導入後、次のコマンドで未翻訳候補を抽出できます。

```sh
node script/desktop-jp/audit-ui.cjs > remaining-ui.json
```

候補には製品名・URL・法的文書も含みます。JSX文字列、表示属性と一部の
表示用変数を調べる補助ツールで、すべての動的な文言を検出するものではありません。
件数がゼロでも完全な日本語化を保証しません。

## 言語パック編集

`app/static/locales/en.ini` と `ja.ini` の `キー=訳文` を編集できます。
`{p0}`、`{p1}` などはリンク・ボタン・強調表示を含む差し込み箇所です。
順番は変えられますが、各差し込み箇所を残してください。
`{branch}`、`{count}` なども同様です。訳文のHTMLは実行されません。
設定の反映には従来どおりアプリの再起動が必要です。
